# CoderQuiz v0.1.3

Question navigation fix, 2026-10-14.

- Starting a run and advancing to the next question explicitly bring the
  question heading into view below the sticky header. This also works when
  touch navigation leaves the heading focused and calling focus again does
  not scroll the page.
- Completing a run brings the result heading into view. Answering, changing
  language and restoring saved progress do not trigger an extra scroll.
- Navigation jumps immediately, including with reduced motion enabled. The
  existing back-to-top button remains available for manual navigation.

Validation: 46 Node tests, including two regressions that failed before the
fix; static build; three deployment tests (the two Linux-specific tests run in
CI). Chromium checks reproduced the retained-focus failure before the fix and
verified the corrected transition at 390px and desktop width, DE/HU, reduced
motion and the existing back-to-top button. A physical iOS retest remains useful.

No dependency, question-bank, saved-progress format or access-control change.
The exact deployed commit and CI archive belong in the GitHub Release record.
