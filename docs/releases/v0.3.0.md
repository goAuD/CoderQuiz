# CoderQuiz v0.3.0

Complete database topic coverage, 2026-10-19.

- Three German/Hungarian packages add 95 questions for LAP-16-01 to LAP-16-19,
  with four choices, one correct answer and an explanation after answering.
- The database module now covers all 19 subtopics. Together with programming
  and Informatik, the catalogue contains 12 packages and 410 questions from
  82 distinct CoderLAP topics.
- Every question links to its source topic in the selected language. The
  reviewed source snapshot is CoderLAP `cefce00affa0f357e7cc3e752abf082cad0ae1d0`.
  Coverage refers to the source self-check positions, not a separate question
  for every detail of the expanded lessons.

The packages build on one another:

1. **Databases 1:** database systems, SQL and SQL/XML, DBMS, CMS, integrity,
   redundancy and data modelling.
2. **Databases 2:** CRUD, normal forms, keys and relationships, indexes,
   database selection, backups and locking.
3. **Databases 3:** business information systems, ERP, BI/data warehouses,
   schema implementation, database access and transactions.

Twenty-five SQL examples run in isolated SQLite databases during development.
They cover joins, constraints, NULL, key/index behavior, aggregation grain and
commit/rollback. A PDO-SQLite fragment is also executed with valid and missing
IDs and an SQL-looking bound value. These are learning examples, not a new
application database. The app displays all code as escaped text.

An XML example and an InnoDB deadlock trace support the reading questions.
InnoDB locking and recovery scenarios were reviewed against primary
documentation; no live MySQL concurrency test is claimed. The SQLite metadata
example explicitly requires version 3.16 or newer.

Validation includes 86 Node tests, all twelve complete quiz runs, bilingual
answer mapping, saved sessions, source links, 17 Python tests on Linux and the
static build. SQL result rows and additional constraint/rollback cases are
checked automatically. The owner reviewed all three packages and confirmed
mobile behavior for the second and third.

Browser checks cover DE/HU, correct and incorrect answers, post-answer
explanations, saved-answer restoration, source links, page-top navigation and
contained code scrolling at 320/390px. Automated screenshot capture timed out;
DOM and geometry checks complement the owner's mobile review.

Existing question IDs and saved-progress formats are preserved. The catalogue,
coverage documentation and per-package preview commands include the new module.
This release adds no runtime dependency, account system, tracking or server-side
learning records. Basic Auth and local browser storage remain in use.

The exact deployed main commit, successful CI run, archive checksum and
production verification are recorded in the GitHub Release.
