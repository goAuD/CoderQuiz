# CoderQuiz v0.1.2

Loading feedback and shared workshop motion, 2026-10-14.

- Catalogue sections and cards use CoderLAP's restrained 360 ms reveal.
  Content remains visible without the effects script or IntersectionObserver.
- Package pages show a skeleton only while their startup scripts are loading.
  It appears after 150 ms of waiting and ends immediately when the first screen
  is ready. Fast loads and question changes have no added delay.
- Failed downloads or startup errors offer a localized retry. DE/HU loading
  feedback works even if translations fail to load or storage is blocked.
- Reduced motion disables reveal and skeleton pulsing. Mobile loading panels
  stack into one column; hidden states also apply to grid elements.

Validation: 44 Node tests, including loading/retry and existing session behavior;
static build and local links; browser checks for delayed and failed question
downloads, successful retry with saved-run restoration, DE/HU, 390 px width,
reduced motion and the JavaScript-disabled catalogue. Screenshot capture timed
out in Vivaldi; physical iPhone appearance still needs user verification.

No runtime dependency, question-bank, saved-progress or access-control change.
The exact deployed commit and CI archive belong in the GitHub Release record.
