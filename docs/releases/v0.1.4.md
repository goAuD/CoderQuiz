# CoderQuiz v0.1.4

Full-page navigation, 2026-10-14.

- Starting a run, advancing to the next question and entering the results now
  scroll to the very top of the page, keeping the navigation and progress
  indicator visible. This refines the heading alignment introduced in v0.1.3.
- The question or result heading still receives focus for keyboard and
  screen-reader navigation. Answering, changing language and restoring saved
  progress do not trigger an extra scroll.
- Navigation jumps immediately, including with reduced motion enabled. The
  existing back-to-top button remains available for manual navigation.

No dependency, question-bank, saved-progress format or access-control change.
The exact deployed commit, validation and CI archive belong in the GitHub
Release record.
