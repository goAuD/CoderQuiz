# CoderQuiz v0.1.0

First static curriculum release, 2026-10-14.

- Four selectable CoderLAP packages: 100 programming questions and 35 Informatik
  questions, across 27 source topics, fully available in German and Hungarian.
- Reviewed source snapshot: CoderLAP `7b14ceebc8bb1c44ad11afcfecc2d5f5ec7867bf`.
  Six programming questions received precise wording/explanation fixes with
  revision increments. All question IDs and source positions stay stable.
- Positive explanations after each answer, with links back to the source topic.
  51 executable JavaScript examples, six HTML examples, three XML examples and
  one pseudocode example in the published banks.
- A normal package catalogue replaces separate preview-only entry points.
  Runs and filters are stored separately per package; language is shared.
  An in-progress quiz can return to topic selection through the new-run button.
- The Műhely frame, local fonts, Lucide icons, mobile layout and back-to-top
  control remain shared with the learning platform.
- CI publishes a static allowlisted archive, with a checksum. Debian promotion
  uses immutable releases and an atomic symlink, with previous releases retained.

Validation: 40 dependency-free Node tests, including complete runs of all four
packages, plus Linux deployment tests for checksums, unsafe paths, promotion and
restrictive umask. Browser checks cover catalogue navigation, DE/HU, mobile
overflow and saved answers. Actual hosting verification is recorded at rollout.

The original independent 100-question law bank remains in Git but is excluded
from production because its editorial review is unfinished. Informatik currently
covers 7 of 43 topics. No database, tracking, accounts, separate hints or shared
login were added. Temporary Basic Auth protects the initial subdomain rollout.
