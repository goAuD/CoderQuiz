# CoderQuiz v0.2.0

Complete Informatik topic coverage, 2026-10-19.

- Five new German/Hungarian packages add 180 questions for LAP-11-08 to
  LAP-11-43, with four choices, one correct answer and explanations after answering.
- Informatik now has 215 questions across all 43 subtopics. Together with the
  100 programming questions, the catalogue contains nine packages and 315
  questions from 63 distinct CoderLAP topics.
- All questions link to their source topics in the selected language. The
  reviewed source snapshot is CoderLAP `cefce00affa0f357e7cc3e752abf082cad0ae1d0`.
  Coverage refers to the source self-check positions, not a separate question
  for every detail of the expanded lessons.
- The new packages progress from CSS, stacks and interfaces through encoding,
  APIs, frameworks, mobile development and .NET to coding conventions and CI/CD.
  Examples use familiar learning-platform development situations and identify
  hypothetical extensions explicitly.
- Thirty-nine new code and configuration examples support the questions.
  PHP, CSS, Java, C#, INI and YAML have appropriate display labels. The app
  displays code as text; JavaScript examples are executed only in development tests.
- The catalogue introduction, coverage documentation and per-package preview
  commands now include the completed Informatik module.

Validation includes 72 Node tests, all nine full quiz runs, bilingual answer
mapping, saved sessions, code output and boundary cases, source references,
three Linux deployment tests and the static build. PHP examples are checked
with the CLI and an isolated SQLite fixture; this is not a MySQL deployment test.
Framework snippets state their prerequisites and serve as reading examples.
The C# snippet was checked against documentation, not compiled locally.

Browser checks cover DE/HU, post-answer explanations, saved-answer restoration,
source links, page-top navigation and contained code scrolling at a 390px
viewport. The owner reviewed the new content and approved the release. These
checks do not establish exhaustive behavior on every mobile device.

Existing question IDs and saved-progress formats are preserved. This release
adds no runtime dependency, account system or server-side learning records.
The current Basic Auth protection and local browser storage remain in use.

The exact deployed main commit, successful CI run, archive checksum and
production verification are recorded in the GitHub Release.
